# 🚀 My Portfolio

A personal portfolio website built using **Python and Streamlit** to showcase my skills, projects, and journey in Artificial Intelligence and Machine Learning.

## ✨ Features
- Personal introduction
- Technical skills showcase
- Interactive project gallery
- AI-powered chatbot using Google Gemini API
- Custom UI and styling

## 🛠️ Tech Stack
- Python
- Streamlit
- Google Gemini API
- HTML & CSS

## ⚙️ Run Locally

```bash
git clone YOUR_REPOSITORY_URL
cd Portfolio
pip install -r requirements.txt
streamlit run App.py
```

## 🎯 Goal

To build a simple, interactive portfolio that showcases my work and explores the integration of AI into web applications.
